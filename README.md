# Durham Weather

A simple weather webpage for Durham, NC that displays current temperature and conditions.

🌐 https://raeyasse.github.io/durham-weather/

## Project Structure

```
project/
├── fonts/
│   └── OCRB-Regular.ttf
├── images/
│   └── durham.png
├── scripts/
│   └── durhamWeather.js
├── styles/
│   └── default.css
└── index.html
```

## How to Run

Visit the link above — no installation required.

## Usage

- Click **Temperature** to display the current temperature in Durham
- Click **Conditions** to display the current weather conditions
